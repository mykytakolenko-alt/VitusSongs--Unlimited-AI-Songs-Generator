Advanced
The length limit is a cap: the model ends the song by itself when the lyrics are done, but cuts it off if the cap is reached first. On weak PCs a shorter cap and faster quality save a lot of time.
For cards with less memory: lower the budget (e.g. 16 or 12) and enable the options below. This will not make generation faster, but helps avoid out-of-memory errors.
Generation takes a few minutes on a fast GPU and much longer on slower hardware.

Song modifier

Edit any song: upload an MP3 / WAV / FLAC / OGG, or press “🎚 Modify” on a song in your library. The result is saved as a new song, so the original stays untouched.

Tempo and pitch are applied without re-composing the music. To change melody, chords or lyrics, use “✎ Edit score” on a library song — YuE2 re-renders it as a new song.

Tips

• In Style, name the language (English, Mandarin…), genre, instruments, vocal type and tempo.
• In Lyrics, use section tags: [Verse], [Chorus]…
• One run = one version. Want a different take? Change the seed.
• Songs are saved in the outputs folder as 48 kHz stereo FLAC.
VitusSongs runs locally on your computer. Music generation powered by the open-source YuE2 model.
